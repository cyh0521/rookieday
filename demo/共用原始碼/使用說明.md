# 舊版展示的共用原始碼

- `viewer/`：M4A1 展示程式、模型、貼圖、字型與 Three.js。
- `game/`：B 流程射擊原型及單檔打包工具。
- `game/visit/`：風格設計中「靶場見習日」的導覽原始碼。
- `Three-MIT.txt`：Three.js 授權。

`game` 會使用相鄰的 `viewer`，請一起保留。正式手繪全靶場版使用 Shooting 根目錄的「assets」。

在 Shooting 目錄執行：

```text
python DEMO/共用原始碼/game/build_standalone.py
python DEMO/共用原始碼/game/build_exploration_scene.py
```

兩者分別輸出至 `DEMO/B流程展示版` 與 `DEMO/風格設計/靶場見習日`。打包會更新對應展示 HTML。

原始開發版使用 ES modules，需透過本機 HTTP 伺服器開啟；各展示版的單檔 HTML 可直接開啟。
