# 靶場見習日：配置導覽展示版

入口檔：`DEMO/風格設計/靶場見習日/靶場見習日-導覽展示版.html`。在 Chrome / Edge 直接開啟即可，程式、Three.js、插畫與所有模型皆已內嵌，不需下載素材或網路連線。需要瀏覽器支援 WebGL。

## 展示範圍

- 依《乙版下冊》p.190–191「靶場搶先看」安排主要分區的相對關係。
- 可愛低多邊形微縮場景：開放式場地、植栽、座椅、告示、指揮與管制設施、急救站及救護車。未設頂棚。
- 主流程：安全規定區 → 配置看板 → 待命線（著裝區）。約 3–5 分鐘，允許自由選擇先後順序。
- 角色自動尋路、手動行走、步道範圍限制、行走動畫、全景／跟隨視角。
- 抵達定點後進入 RPG 人物立繪、對話及選擇事件；答錯顯示說明，可重試。
- 額外可走訪指揮臺、預備槍／彈藥管制區及急救站，閱讀簡短介紹。
- 三份筆記保存在同一瀏覽器的 localStorage。隱私模式、搬移檔案或瀏覽器清除資料後，紀錄可能不保留。
- 無射擊操作。入口、景觀、人物比例與道路為遊戲設計；不是實際靶場的施工圖或現場活動指令。

## 操作

| 操作 | 功能 |
| --- | --- |
| 點左側站點／場景標籤 | 自動走到站點，抵達後開啟事件 |
| 點步道地面 | 自動行走到該處 |
| WASD／方向鍵 | 手動移動，會取消自動路線 |
| E／畫面互動按鈕 | 開啟附近站點事件 |
| 滾輪 | 縮放 |
| 右上「全景／跟隨」 | 切換鏡頭；手機預設跟隨 |
| 見習手冊 | 查看已收集筆記 |
| 重新開始這次見習 | 清除該展示版進度並回到入口 |

## 原始碼與建置

- `index.html`：介面、RPG 教官 SVG 立繪。
- `style.css`：桌機／手機版面。
- `world.js`：程序化 3D 資產、教材分區、景觀及人物；重複靜態模型以 InstancedMesh 合批。
- `core.js`：站點、碰撞範圍、A* 尋路與進度驗證。
- `main.js`：渲染、操作、動畫、事件與保存。
- `core.test.mjs`：主要路線、區域限制與資料清理測試。
- `qa.cjs`：本機 Playwright 端到端驗證與截圖；依目前工作環境的 Chrome／runtime 路徑執行。

在專案根目錄執行 `python game/build_exploration_scene.py`，會同步產生 `DEMO/風格設計/靶場見習日/` 內三個入口檔：`靶場見習日-可實作場景.html`（本機 Three.js 依賴）、`靶場見習日-單檔場景.html` 與 `靶場見習日-導覽展示版.html`（兩者內容相同且可離線）。開發時可用靜態 HTTP 伺服器開啟 `game/visit/index.html`。

執行核心測試：`node --test game/visit/core.test.mjs`。

圖像來源：所有幾何模型、Canvas 材質與 SVG 立繪為本展示版以程式建立。教材用於分區與內容參照，未將課本照片嵌入遊戲。Three.js r170 使用 MIT 授權，見根目錄 `Three-MIT.txt`。
