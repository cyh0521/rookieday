# B 流程：臥姿靶場原型

2026-10-27。優先實作 B 流程；A 模組與教師系統留待後續。

## 開啟

以桌面 Chrome 或 Edge 開啟 `DEMO/B流程展示版/B流程-臥姿靶場.html`。這是約 6.8 MB 的單檔版本，已包含 Three.js、M4A1 模型、貼圖與字型，執行不依賴 CDN。建議橫向視窗、滑鼠與鍵盤；手機不是本版主要操作裝置。

## 本版流程

1. 入口：確認裝備與控制方式。
2. B1 引導：固定 03 號靶位、臥姿低視點，完成 3 次遊戲射擊。
3. 回顧：檢視落點、命中次數與遊戲環分。
4. B2 自主練習：兩個回合，各 5 次，每回合使用新的紙靶。
5. 總結：合計兩個自主回合，可切換各回合紙靶、下載目前落點圖或重新開始。

沒有倒數時間。新回合先換彈匣；換彈、暫停與回顧時不能射擊。圓環與 1–6 分計分屬於本遊戲設計。

## 操作

| 輸入 | 功能 |
|---|---|
| 滑鼠移動 | 調整視角 |
| 滑鼠左鍵 | 射擊 |
| 滑鼠右鍵 / R | 換彈匣 |
| 空白鍵 | 切換機械瞄具視角 |
| Esc | 暫停 / 繼續 |
| 畫面下方按鈕 | 相同操作的替代控制 |
| 鎖定游標 | 瀏覽器支援時使用相對滑鼠移動；Esc 釋放並暫停 |

設定提供音量、靈敏度、畫質與減少晃動。離開視窗或開啟設定會自動暫停。預設為低晃動。

## 已實作與界線

- 戶外棚架、地墊、5 座編號紙靶、土堤、側牆及簡化植被；射手固定在地墊上的低視點，無站姿射擊桌。
- 現有 CC0 M4A1 的 PBR 材質、機械瞄具視角、程式換彈匣與簡化前臂。
- 射線落點、回合狀態管理、彈數限制、音效及 PNG 落點圖匯出。
- **T91 尚未加入**：待取得可用模型並核對外觀。沒有將 M4A1 改名為 T91。
- 這是可玩原型；環境與前臂仍為簡化模型，未含完整角色骨架、全身姿勢辨識、真實彈道或多人教師後台。
- 最後一次總結只保存在同瀏覽器的 localStorage，無伺服器上傳；本版沒有歷史紀錄查詢畫面。

## 維護

驗證記錄：本機 HTTP 瀏覽器已走完 3 + 5 + 5 次、每回合回顧、兩回合總結、右鍵換彈、空白鍵瞄具，以及換彈中暫停／恢復；打包版載入時未記錄 console error。核心規則測試通過。瀏覽器工具限制只能開啟 HTTP/HTTPS，故尚未透過工具驗證直接雙擊 file:// 的啟動方式。未在不同規格的教室電腦測量效能。

`main.js` 管理 UI 與輸入；`core.js` 管理回合；`world.js` 為場景；`weapon.js` 為模型與動畫。

執行 `node game/core.test.mjs` 可驗證回合、射擊門檻、換彈、暫停、未命中、重設及計分邊界。

修改後執行 `python DEMO/共用原始碼/game/build_standalone.py`，重新產生 `DEMO/B流程展示版/` 內的單檔 HTML。開發版 `DEMO/共用原始碼/game/index.html` 需透過本機 HTTP 伺服器開啟。
